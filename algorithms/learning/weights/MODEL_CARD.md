# CNN + GRU 模型卡

发布权重：`driver.pt`；真实 CPU 训练，无外部预训练参数，无几何专家回退。

- 架构：`cnn_gru_v1`，401,259 参数，160×96 RGB + 提示通道，4 层卷积、96 维 GRU、直接动作与可见性头。当前训练使用默认绿色标记，提示通道仅预留其他类型扩展。
- 模型 ID：`cpu-bc-seed42-epoch8`（DAgger 数据上的监督拟合第 8 轮）。
- 文件大小：1.54 MiB。
- SHA-256：`8184a5a2effc11a935e2033740814b56be2c74cb173720503423e104ab44a0d0`。推理输出 debug 同样记录实际加载文件的 SHA-256。
- 基础训练：64 条训练轨迹 / 14,252 帧，16 条验证轨迹 / 3,618 帧；CPU PyTorch 2.7.1+cpu，20 轮，种子 42，AdamW，初始学习率 0.0005。
- DAgger：由基础训练第 7 轮策略访问状态，25% 专家行为混合；合并后 128 条训练轨迹 / 28,901 帧，32 条验证轨迹 / 7,311 帧。它们对应 64 个独立训练场景与 16 个独立验证场景，每个场景有两条行为轨迹。继续训练 8 轮，初始学习率 0.00015。
- 训练监督可读私有路线；部署 `algorithm.py` / `model.py` 不导入专家、仿真、地图或评分模块。
- 训练种子 0–7；离线验证 201–202；闭环选择 203–204；独立测试 1001–1005。按完整场景分组，不随机拆相邻帧。

闭环选择：15/16；保留核心测试：**35/40（87.5%），1 次非法换线**。失败均在平行干扰线，4 次偏离终止、1 次非法换线；全部保留。其余七类各 5/5。这是教学学习基线，不能称为 SOTA，也没有达到 95% 独立成功率。

网络以 10 Hz 更新，平台以 20 Hz 执行物理步。可见性过低时请求 LOST，由统一执行规则停车；该概率不代表目标身份正确或闭环成功率。无点/区域提示、颜色修改、任意车辆/相机或真实道路性能保证；当前权重对未训练提示明确报错。

`collection-policy.pt` 是复现 DAgger 采集所需的早期策略，不是发布驾驶模型。`bc.*`、`dagger-model.*`、`acquisition-model.*` 与 `driver.*.json` 保存真实参数和逐轮日志；采集计划与每条轨迹索引见 [数据摘要](../../../artifacts/algorithms/training-data.json)，完整选择记录见 [model-selection.json](../../../artifacts/algorithms/model-selection.json)。复现入口见 [算法说明](../../../docs/algorithms.md)，结果见 [验收报告](../../../docs/algorithm-results.md)。
