# CNN + GRU 复杂路线模型

- 文件：`driver-complex.pt`；401,259 参数，CPU 训练和推理。
- SHA-256：`d87a1d6e0c16823b5ac2b559aa96b827f5eabd868f779aaf0ae035b555574999`。
- 输入：160×96 RGB + 显式绿色标记通道，过去动作、轴距、最大转角和时间间隔；`input_version=rgb_marker_v2`。
- 输出：10 Hz 直接转角、速度和可见性。可见性不是身份正确率；无专家控制器回退。
- 支持范围：默认绿色标记，kinematic_v1 / render2 和 inertial_v2 / render3。公开标记颜色或提示类型不匹配时明确拒绝。

第二阶段实际数据共 252 条轨迹、67,014 帧，其中训练 200 条 / 53,048 帧，离线验证 52 条 / 13,966 帧。包括历史数据、两份用户开发地图增强、独立套圈与平行弯线、真实学生闭环 DAgger 和短起步轨迹。用户地图不作为未见测试；6001–6002 未进入训练。

初始化来自几何扩充阶段第 2 轮权重，其 SHA-256 为 `95af9a0cefd914ccdea98fdfc07ef13d6c5384a1c0de587a5de8022a100d6ff1`；该阶段从历史驾驶权重开始。发布版本为显式标记 / DAgger 阶段第 2 轮，是首个通过固定 20/20 独立开发验证及 2/2 用户地图回归的候选；在保留测试前冻结。之后完成的训练轮次没有用于针对保留测试换权重。

独立测试：默认八类 8/8，复杂几何 7/8，共 15/16。剩余失败为 `parallel_curve / 6001 / inertial_v2` 末段切入干扰线。没有通用避障能力或任意地图保证。

完整命令与来源见 [学习说明](../../../docs/custom-learning.md)，[选择记录](driver-complex.selection.json)、[真实训练日志](driver-complex.training.json) 和 [逐数据文件摘要](driver-complex.data.json) 保留复现信息。两个历史权重文件保持原样，可显式指定 `checkpoint` 复现旧策略。
