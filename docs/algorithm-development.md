# 算法开发与固定评测约定

用户已于本轮授权进入正式算法阶段。实现目标为扫描线 PID、时序拓扑视觉 + 调速 Pure Pursuit、时序视觉 + 预测控制、图像时序神经网络四类方法。复用公共 SDK，部署算法仅读取图像、公开标定、提示、时间与车辆约束；不读取地图、真实位姿、种子、评分或未来帧。

控制方法参考 Nav2 Regulated Pure Pursuit 的曲率调速思想，学习方法参考 NVIDIA 端到端驾驶与 DAgger 数据聚合论文；独立实现适配本平台，不复制第三方代码、不预先标为 SOTA。

开发 / 训练种子使用 0–99，验证使用 201–204；最终测试使用 1001–1005。以完整场景族和种子分组，测试集不参与训练或调参。所有八类场景固定保留，评分阈值不变。压力场景与核心场景分开报告。模块化算法以 >=95% 独立核心集成功率和零非法换线为优化目标，未达到时报告实际结果。

依次实现视觉结构与身份跟踪、控制器与开发集闭环、训练数据与可选 CPU 训练、冻结参数并独立评测、浏览器与协议回归、整理真实权重状态和失败案例。保留消融：关闭时序关联、关闭连通性约束。学习推理禁止调用模块化算法作为动作回退；缺失权重必须明确失败。
