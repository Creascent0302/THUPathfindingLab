# 新场景与惯性车辆评测

2026-09-19，新版默认场景的独立测试共 64 回合：Temporal Pursuit 16/16、Temporal MPC 16/16、CNN + GRU 15/16、扫描线 PD 12/16 成功。失败全部计入分母。两个几何方法可作为当前默认环境下的强参考；16 回合不足以推出真实道路、任意自定义配置或学术 SOTA 的结论。

## 测试配置与口径

- 场景：八个生成族，各使用独立保留种子 `5001`、`5002`，每个算法 16 回合。同一种子使用相同的路径、初始姿态、相机与路侧物件。
- 图像：渲染版本 `3`，640×360 RGB，默认相机俯角 0.38 rad，路侧 10 个立体物件、多段场景 18 个；包括透视遮挡、表面明暗与投影阴影。
- 运动：`inertial_v2`，物理步长 0.05 s；速度响应 0.18 s、偏航响应 0.12 s、横向响应 0.10 s、加加速度限制 6 m/s³、横向加速度限制 3 m/s²，其余车辆参数使用项目默认值。
- 每回合最多 4000 个算法帧，之后另记连续制动至静止的轨迹。任务终止后不增加进度，刹停过程仍检查碰撞并统计平顺性。
- 评分器 / 总分版本均为 `2.0`。目标接入距离 0.20 m、接入方向误差 0.45 rad；跟踪距离 0.24 m、方向误差 0.65 rad，连续偏离 2 s 终止；非法换线距离 / 优势 / 持续时间为 0.14 m / 0.035 m / 0.5 s；终点剩余距离 0.18 m。这些核心阈值没有放宽。
- 策略只接收公开 SDK 图像、标定、时间、提示和车辆限制。真实位姿、路线与物件几何只供仿真和评分使用。

快速评测的推理时间包括图像解码和 `step`，不含渲染、初始化与 Worker 传输。本次多个离线批次并行，CPU 竞争会影响实时性分项；不能根据下面接近的总分认定某个控制器具有稳定速度优势。前端批量评测使用真实 Worker，耗时口径另含协议开销。

## 适配与开发验证

模块化方法改用公共纯函数 `pathlab/dynamics.py`，自行维护命令驱动的 8 维运动估计；速度向量经过车体坐标变换时保留侧向动量。MPC 的 63 组候选也使用相同积分器，Pure Pursuit 的前视和调速考虑响应延迟、制动距离与横向加速度限制。该复用不开放仿真真值。

扫描线加入响应延迟前馈和较低巡航速度。开发验证种子 203 曾发现缩短失线保持会把车辆停在终点盲区，约完成 96%；据此恢复有限 1.5 s 保持、惯性场景失线速度限制为 0.35 m/s。修复依据开发日志，不使用 5001–5002 调参。修复后的验证种子 204 为 5/8，失败分别是 parallel、hairpin、repeated；该开发批次上限 1800 帧，仅用于回归诊断，不与 4000 帧保留集混排。

冻结默认图像后的模块化验证种子 203：Pursuit 8/8、MPC 8/8。新版 CNN 的完整闭环验证种子 203–204 为 **14/16**：两次 parallel 失败均未接入目标，随后发生碰撞，完成度均为 0；它们保留在验证报告中。验证成功率不能替代独立测试结果。

终止滑行冻结功能在评测期间完成。正式模块化报告已使用最终 `begin_coasting()` 重新运行；CNN 的三个验证 / 测试失败均完成度 0、未接入，分数 0；扫描线失败末帧已经静止，没有额外制动帧。因此冻结滑行进度不会改变这些保存失败的完成度、标签或分数。没有通过重标注掩盖失败。

早期 `inertial-transfer-before` 使用较陡相机分布；早期 `inertial-core` 队列曾跨越扫描线源码调整，已标记 `SUPERSEDED.md`，均不作为上述正式对比的数据源。最终结果只取下面列出的三个冻结批次。

## 真实学习训练

新权重 `algorithms/learning/weights/driver-inertial.pt` 由旧的真实训练模型初始化，在实际采集的惯性轨迹上微调，没有随机权重演示或几何专家回退。

- 训练 64 条轨迹、14,146 帧；验证 32 条轨迹、7,338 帧。两种相机分布重复访问相同完整场景，独立场景数是训练 32、验证 16。
- 训练种子 0–3，离线验证 201–202；两组相机俯角范围为 0.33–0.47 与 0.46–0.60 rad，同时随机化外观和执行器响应。每条轨迹保存真实使用的完整场景配置及数据校验值。
- CPU PyTorch 2.7.1+cpu，4 线程，种子 42，AdamW，学习率 0.0001，12 帧序列，接入阶段权重 3，训练 6 轮，实际耗时 **378.8 s**。
- 按完整验证集监督损失选择第 6 轮。归一化转向 MAE 为 0.02125，速度 MAE 为 0.00853 m/s；这是离线动作误差，不是闭环成功概率。
- 新权重 SHA-256：`09e31baca684b4046e416765a314085aea2bb1c74086d4aa55814ebd4609ffdb`。
- 初始化的历史权重 SHA-256：`8184a5a2effc11a935e2033740814b56be2c74cb173720503423e104ab44a0d0`。历史 `driver.pt` 保留，默认加载器按公开车辆模型选择新旧权重。
