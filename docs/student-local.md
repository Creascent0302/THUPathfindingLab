# 学生实验平台：本地运行

解压整个发行包到一个可写目录，不要只复制其中的可执行文件。发行包自带 Python、NumPy、OpenCV 和 SDK，无需安装 Python 或 Node.js，也不需要联网。

- Windows：双击 `PathLab.exe`。也可以在终端运行 `PathLab.exe`。
- Linux：在解压目录运行 `chmod +x PathLab`，然后 `./PathLab`。

浏览器打开 **http://127.0.0.1:8000**。保持启动终端打开，结束时按 Ctrl+C。
不同操作系统使用各自构建的发行包；Linux 包不能在 Windows 中直接运行。

## 第一次实验

1. 选择场景和“手动驾驶”，创建实验，用页面按钮或方向键操作。
2. 在“算法提交”下载空白模板，实现 `algorithm.py` 中的 `StudentAlgorithm`。
3. 将代码和辅助文件打包为 ZIP 上传，选择动作、局部路径或感知输出。
4. 运行后查看摄像头、调试输出和运行记录；在评测中心选择自己的多个版本进行批量比较。

初始安装不包含任何寻迹或避障实现。空白模板只返回停车指令。接口细节见 `student-guide.md`；`sdk/pathlab/sdk.py` 可供编辑器查看类型。模板提交时不需要把 SDK 打包进去。

自定义地图、障碍物、干扰线及相机、车辆参数可以在地图编辑器设置。平台保留统一的局部路径执行器，只将你提交的米制路径转换为车辆动作，不负责识别道路或规划绕行。

## 数据保存在哪里

数据位于程序旁边的 `artifacts/`，包括地图、上传代码、素材、运行记录和批量报告。关闭或刷新网页不会清空这些数据。备份时先停止程序，再复制整个 `artifacts/`。

也可以指定其他本机目录：

```text
PathLab.exe serve --data-dir "D:\PathLabData"
./PathLab serve --data-dir "$HOME/PathLabData"
```

同一数据目录只启动一个实例。运行记录限额 2 GiB，可在页面删除；地图和代码另行保存。更换发行包时复制数据目录即可，建议保留旧包以复核旧记录。

## 通过内网访问

在运行程序的电脑上启动：

```text
PathLab.exe serve --lan
./PathLab serve --lan
```

其他电脑浏览器打开 `http://运行电脑的内网IP:8000`。Windows 用 `ipconfig`、Ubuntu 用 `hostname -I` 查看 IP。两台电脑需要能互相访问，系统防火墙也需要允许该端口。端口占用时加 `--port 8001` 并使用对应网址。

内网访问共享同一个工作台，数据保存在**运行程序的电脑**，不会保存在访问网页的其他电脑。推荐每位同学在自己的电脑运行。本平台会执行上传的 Python 代码，独立进程不是恶意代码沙箱，只应向可信同学开放；不要开放到公网。

## 依赖和实验边界

发行包的依赖是固定的，上传 `requirements.txt` 不会自动安装库。常用标准库（如 math、collections、json、random）、NumPy、OpenCV 与 SDK 可用；需要其他第三方库时由教师统一重新构建发行包。

不附后端源码不代表不能逆向或篡改。网页脚本、公开接口和评测指标可以查看。学生本地结果用于自测，课程最终评分应由教师使用原始提交代码在可信环境重新运行。
