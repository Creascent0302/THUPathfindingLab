# 课堂演示：从图像输出轨迹，再由平台开车

本版在 `student/local-lab` 分支维护，供学生在 Linux/macOS 本地运行；Windows 使用 WSL。环境安装见 [学生使用手册](student-local.md)。平台无需公网、域名或云存储。

## 第一次演示

运行 `python run.py`，打开网页。选择「01 · 直线入门」和「教学示例 · 车前直线」，执行依据会自动切换到「车辆坐标系局部路径」，点击启动。这个示例是 [学生指南](student-guide.md) 中的原样代码，能读图并展示接口，但路径是人为构造的车前直线，不会识别弯道。

再选择「课堂演示 · 时序拓扑轨迹」，从单弯逐步切换到干扰线和螺旋地图。算法画面的选中线应始终属于同一条有序路线。可暂停、单步、查看输出与运行记录。

所有新仿真都从路线首点出发，后轴中心位于首点，朝向首段，也就是起点箭头方向，初始速度为零。地图编辑、导入预览、单次运行和批量评测遵守同一规则。旧的点/区域提示不会阻塞仿真；历史记录按当时内容回放。

## 学生真正需要输出什么

```python
return AlgorithmOutput(
    status="TRACK",
    local_path_m=[(0.4, 0.0), (0.7, 0.06), (1.0, 0.18)],
)
```

这些点使用当前车辆后轴坐标系，x 向前、y 向左，单位米，按行驶顺序排列。上面的点逐渐向左弯。`centerline_px` 只用于图像叠加；只有它而没有 `local_path_m`，不能在路径模式驾驶。

学生无需返回 `action`，也无需计算油门、速度或转角。没有可靠路线时返回 `LOST`；平台请求制动，车辆依惯性减速。发现两条路线无法区分时应返回 `AMBIGUOUS`，不能为了完成度随便选择一条。

## 时序拓扑示例如何工作

入口是 [temporal.py](../algorithms/temporal.py) 的 `StudentAlgorithm`。它只使用相机图像、标定、时间戳和公开车辆限制。没有读取地图真值、车辆真实位置或评分器。

1. **把透视图变成地面坐标。** [vision.py](../algorithms/vision.py) 的 `BirdEye` 使用单应矩阵，把当前图像采样到鸟瞰网格；不在镜头中的区域不参加识别。这样近远处线宽更接近，可以用米作为关联门限。
2. **提取候选，不先把多条线平均。** 利用线与背景的灰度差、颜色和宽度筛选线像素，再细化成骨架，分离连通分量。图像里出现多个回返路段时，它们仍是多个候选或同一骨架上的不同分支。
3. **第一帧使用已知起步关系。** 车辆已经在起点，朝向为局部 x 正向。候选必须能由起点沿直线或满足转弯半径的圆弧连续到达；平行偏置线不会因为更长、更黑就优先。关联代价过于接近时停车。
4. **后续帧预测旧路线的位置。** 车辆运动后，上一帧的路线需要平移、旋转到新的车体坐标系。示例用 [motion.py](../algorithms/motion.py) 和公开车辆模型估计这种变化，保留近处可见的历史点，避免急弯时把可靠记忆全部丢掉。
5. **用历史身份约束本帧选择。** 比较候选与历史支撑点的距离和方向。仅在关联门限内更新，禁止每帧重新选择全图最近的线。附近出现另一圈螺旋时，时间连续性帮助保住目标身份。
6. **沿骨架连接关系追踪。** 从关联位置沿局部方向向前追踪，遇到分支结合方向连续性选择；路径按骨架经过的顺序输出，不按 x 坐标排序。回头弯中 x 可以先增大后减小，排序会破坏真实拓扑。
7. **缺失时有界预测。** 短时不可见时沿已观测路线预测并降低置信度；超过记忆时限则停车。看到终点后，可在进入相机近端盲区时短时保留终点记忆。算法自报完成不替代评分器判定。
8. **返回轨迹，统一执行。** 每帧返回 `local_path_m`、用于叠加的 `centerline_px`、置信度和诊断；`action` 始终为空。

第 4 步为了预测自运动，会在算法内部调用同一个路径执行器，估算平台可能发出的动作；该估计只用于迁移图像记忆，不是读取真实遥测，也不作为算法输出。延迟或掉帧压力模式下，实际执行可能不同，预测误差会增加。学生可进一步研究视觉里程计，但基础作业无需自己写车辆控制器。

## 平台怎样把点转换为动作

调用链为 `Run._step → execution_action → PurePursuit.action → Vehicle.advance`，代码见 [engine.py](../pathlab/engine.py) 和 [adapters.py](../pathlab/adapters.py)。

执行器按路线顺序，在当前前向段与半径 0.57 m 的前视圆相交处插值取点 `(x,y)`，然后计算：

```text
曲率 κ = 2y / (x² + y²)
目标转角 δ = atan(轴距 × κ)
```

转角限制在车辆允许范围内。目标速度随曲率和置信度降低；惯性、转角变化率、制动和横向加速度限制仍由车辆模型执行。路径过短时使用当前前向段末点，完全在车后时制动。路径执行器不负责识别线，也不会把米制路径当作要一次走完的全局导航。

本次修正的关键点：

- 在折线段上插值，而不是跳到第一个超出前视距离的采样点。往同一线段插入更多点，不应改变转向。
- 当前前向段结束后，不跳到回返路线再次进入车前的部分。
- 路径模式忽略 `action`；只有像素线而缺失米制路径时明确报错。
- 低置信度、丢线和制动仍经过物理模型，不把真实速度瞬间清零。

## 无障碍课程地图

全部地图为 `core`，无物件、无合成遮挡，遵守相邻点间距、车辆曲率、路线间隔和起步可见性限制。新预设直接出现在主页，无需导入。固定 seed=7 的 JSON 位于 `scenarios/challenges`；`scripts/install_challenges.py` 可将它们作为独立副本放入地图库，自动处理重名，不覆盖已有地图。

| 关卡 | 训练重点 |
|---|---|
| 01 直线 | 接口、坐标、基本阈值 |
| 02 单弯 | 反投影和转弯方向 |
| 03 连续 S 弯 | 方向变化、时序稳定 |
| 04 大角度急弯 | 路径弯曲和可见范围 |
| 05 紧凑回头弯 | 半径 0.62 m，多段可见 |
| 06 双侧平行干扰 | 干扰中心线距目标 0.16 m |
| 07 近贴断续干扰 | 间距约 0.105～0.125 m，干扰反复出现/消失 |
| 08 密集往返路段 | 半径 0.60 m，连续相邻回返 |
| 09 极限连续反向弯 | 半径 0.58 m，接近默认车辆约 0.559 m 的最小半径 |
| 10 内收螺旋 | 2.2 圈，相邻圈径向间距 0.40 m |
| 11 外展螺旋 | 从小半径开始，增加距目标 0.14 m 的伴随干扰 |
| 12 密绕螺旋 | 2.6 圈，圈间距 0.38 m，双侧各 0.12 m 的伴随干扰 |

默认车宽 0.28 m，目标路线非相邻路段至少相隔车宽加 0.08 m；干扰线可以更近，但不能与目标线相交或违反线宽间隔。新场景统一校验，直接导入 JSON 也不能绕过约束。首尾几何不变时，相机太窄而看不到起步路线会明确报错。

## 复现测试与教学建议

```bash
.venv/bin/python -m pytest -q
.venv/bin/python scripts/browser_student.py
.venv/bin/python scripts/verify_classroom.py
```

闭环脚本使用真实 Worker、图像、SDK、路径执行器、惯性车辆和评分器。默认执行 12 张图 × 3 个种子（7、1009、42，含左右镜像）的时序拓扑示例，另加直线示例。每次测试在 `.cache/classroom-acceptance/trial-*` 保存代码摘要、完整场景、全部逐帧轨迹/输出/动作、失败原因和 `summary.json`，不修改个人数据。它是本版本的回归测试，不表示任意视角、材质或遮挡下都必然成功。

建议课堂先固定车辆、相机、步长和执行模式，让同学只改变识别算法，便于解释差异；基础课程用 01～05，进阶用 06～12。评分时保留一组未向学生公开的地图，在教师电脑统一运行提交包。演示代码有完整识别思路，若不希望学生直接复用，应在课堂说明哪些部分可引用、哪些需要独立完成。先用固定种子复现问题，再扩展随机种子和相机扰动。

本地版本没有账号隔离；每人运行自己的实例最简单。内网共享实例会共享实验数据与上传代码执行环境，适用于可信同学。macOS 和不同 Linux 架构需要各自验收，Linux 包不能直接在 Mac 上运行。
